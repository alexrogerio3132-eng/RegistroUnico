Como ler os números

Download só acontece na primeira vez de cada modelo; depois fica guardado no aparelho. O que importa no dia a dia é a coluna Leitura.

Rápido ×2 é o que o app faz hoje: modelo leve, lendo duas vezes.
Bom ×1 é a proposta: modelo pesado, lendo uma vez só.
Só dígitos mostra o ganho de travar o alfabeto quando o campo é CPF, RG ou data.
